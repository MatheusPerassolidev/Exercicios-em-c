Exercícios de lógica de programação desenvolvidos durante meus estudos de Engenharia de Software.

## Controle de velocidade

Arquivo: controle_velocidade.c

O programa recebe a velocidade de um veículo e o limite permitido.
Depois, exibe uma classificação conforme as regras do exercício.

Conceitos praticados:
- Variáveis inteiras;
- Entrada e saída com scanf e printf;
- Condicionais if, else if e else;
- Operadores de comparação;
- Cálculo de porcentagem.

A classificação das multas é didática e segue o enunciado do exercício.
